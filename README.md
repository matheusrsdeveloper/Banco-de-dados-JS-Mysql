# Projeto Acadêmico: Sistema com MySQL, JavaScript e Postman

## Descrição do Projeto
Este projeto foi desenvolvido como atividade acadêmica com o objetivo de criar um sistema simples utilizando **JavaScript**, **MySQL** e testes de API com **Postman**. Ele permite a interação com um banco de dados relacional, realizando operações básicas de CRUD (Create, Read, Update e Delete).

---

## Tecnologias Utilizadas
- **JavaScript (Node.js)**: Linguagem de programação principal do backend.
- **MySQL**: Banco de dados relacional para armazenar informações.
- **Postman**: Ferramenta para testes de API e requisições HTTP.
